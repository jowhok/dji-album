## 1. 需求摘要

| 模块 | 要点 |
|---|---|
| 媒体源 | 局域网 NAS（SMB），相机上传目录：`<照片根>/YYYYMMDD/`，含 `.mp4`（高清）、同名 `.lrf`（低清代理）、`.jpg`（照片） |
| 预览 | 瀑布流、按日期分区（最新在上）、视频/照片分工作区、缩略图、点击弹出播放器；默认播 `.lrf`，可切换 `.mp4`；组内可按拍摄时间或大小排序 |
| 收藏 | 红心标记（瀑布流 + 播放页均可），本地记录、不动 NAS 文件；收藏夹单独视图 |
| 删除 | 软删除 → 回收站（仅本地记录）；回收站内可单选/多选批量「彻底删除」，二次确认后真实删除 NAS 文件（`.mp4` + 同名 `.lrf` 成对删除） |
| 其他 | UI 好看、支持全屏/窗口模式 |

## 2. 技术选型（推荐）

- **框架：Electron + React + TypeScript + Vite**（electron-vite 脚手架）
  - HTML5 `<video>` 原生流式播放、UI 表现力最强；无边框自定义标题栏 + 全屏 API 成熟
  - Chromium 内置 H.264/AAC 解码，`.lrf` 本身就是 MP4 容器（H.264），可直接播放
- **NAS 访问：Windows 原生 SMB（UNC 路径）**
  - 软件直接读 `\\<NAS 主机>\<共享名>\<照片根>\...`，无需挂载
  - 首次运行引导配置地址/账号，密码写入 Windows 凭据管理器（不落明文）
- **流媒体：主进程内置本地 HTTP 服务（127.0.0.1:随机端口）**
  - 代理 UNC 文件并支持 Range 请求 → 播放器可边下边播、任意拖进度条，关闭即停
- **本地数据：SQLite（better-sqlite3）**
  - 三张表：`files`（索引缓存）、`favorites`（收藏）、`trash`（回收站）
- **缩略图：sharp（JPG 压缩）+ ffmpeg-static（视频从 `.lrf` 抽帧，秒级）**
  - 缩略图缓存到 `%APPDATA%/DJI-Album/thumbs/`，离线可看
- **UI：深色相册风 + 无边框自定义标题栏，F11 全屏**

### 关于 DJIWidget 的说明
GitHub 上 DJI 开源的 DJIWidget 是 **iOS/Android** 播放组件，不适配 Windows。好在 `.lrf` 是标准 MP4 容器（ftyp isom / H.264），Electron 的 Chromium 可直接解码播放，**无需引入任何 DJI 组件**。个别异常文件用 ffmpeg 转封装（remux）兜底，不重编码。

## 3. 数据结构（SQLite）

```sql
files     (path PK, name, type(video|photo), dir_date, size, taken_at, thumb, indexed_at)
favorites (path PK, created_at)
trash     (path PK, deleted_at, note)
```

- 路径统一用 NAS 绝对 UNC 路径做主键，NAS 侧文件不变动
- 收藏/回收站删除均只写本地库；「彻底删除」才调文件系统删 UNC 文件（`.mp4` + `.lrf` 成对）

## 4. 里程碑（每步交付可运行版本）

| 里程碑 | 内容 | 验证方式 |
|---|---|---|
| M1 | 脚手架 + NAS 连接引导 + 全量扫描建索引 | 扫描 418 文件入库，断网有明确错误提示 |
| M2 | 缩略图生成 + 瀑布流（日期分组/最新在上/视频照片工作区/排序切换） | 19 个日期组渲染，切换排序即时生效 |
| M3 | 播放弹窗（默认 LRF、切换高清、流式拖进度、上/下一个、关闭即停） | 播放/拖动/切换码率正常 |
| M4 | 收藏（红心标记 + 收藏夹视图，本地库） | 标记持久化，重启不丢 |
| M5 | 回收站（软删 + 恢复 + 批量彻底删除 + 二次确认 + mp4/lrf 成对删） | 删除后 NAS 侧两文件消失，回收站可恢复 |
| M6 | 打磨：全屏/窗口、快捷键、空态/加载态/错误态、设置页（NAS 配置、缓存清理） | 冒烟全流程 |

## 5. 风险与兜底

| 风险 | 兜底 |
|---|---|
| 个别 `.lrf` 容器不规范导致无法直接播 | 自动 ffmpeg remux 到本地缓存再播 |
| 视频缩略图依赖 ffmpeg | ffmpeg-static 随安装包分发（约 +80MB），免用户安装 |
| SMB 凭据/网络失败 | 连接引导页 + 重试 + 明确错误态，不白屏 |
| NAS 侧文件被外部改动（索引漂移） | 启动时校验存在性，失效条目自动淡出并提示刷新 |
